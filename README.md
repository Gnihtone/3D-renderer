# Имплементация 3д-движка

## Используемые библиотеки

* SFML -- Для отображения на экран
* GLM -- Для работы с матричными вычислениями
* Assimp -- Для импорта

## Сборка и запуск проекта

1. `git clone https://github.com/Gnihtone/3D-renderer.git`

2. `git submodule update --init --recursive`

3. `mkdir build`

4. `cd build`

5. `cmake -G Ninja ..`

6. `ninja`

7. Execute file in `build/bin` directory.
